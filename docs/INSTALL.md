# 真机安装与权限（Honor 200 / MagicOS 9）

> 菜单名随系统版本略有差异；找不到时在设置里搜关键词（自启动 / 后台活动 / 电池优化 / 锁屏通知）。

## 1. 装 APK

构建产物：`dist\superwaking-debug.apk`（debug 签名，个人侧载足够）。

任意一种方式传到手机：

| 方式 | 做法 | 备注 |
| --- | --- | --- |
| USB 文件传输 | 手机选「传输文件」，把 APK 拖到 Download | 不需要 adb |
| 微信/QQ 文件传输助手 | 发给「文件传输助手」→ 手机打开 | 微信可能改后缀，改回 .apk |
| 网盘 | 上传后手机下载 | 最省事 |

安装时 Honor 会提示「未知来源应用」，允许一次即可。

## 2. 首次打开按顺序给权限

点「检查 / 申请权限」，一次处理一项，重复点到全部 ✓：

1. 通知权限（系统弹窗）
2. 精确闹钟（`USE_EXACT_ALARM` 正常应自动授予；若列表显示 ✗，去「设置 → 应用 → 特殊访问权限 → 闹钟和提醒」打开）
3. 全屏通知（Android 14+ 需要单独开关）
4. 电池优化 → 选择「不允许限制」

## 3. Honor 必做（否则夜里会被杀）

| 项目 | 路径（大致） | 目标状态 |
| --- | --- | --- |
| 应用启动管理 | 设置 → 应用 → 应用启动管理 → SuperWaking | 关闭「自动管理」，三个开关（自启动/关联启动/后台活动）全开 |
| 电池优化 | 设置 → 应用 → SuperWaking → 耗电详情 | 「不受限制」 |
| 锁屏通知 | 设置 → 通知 → SuperWaking | 允许锁屏显示、横幅 |
| 悬浮窗/后台弹窗 | 设置 → 应用 → 特殊访问权限 → 悬浮窗 | 允许（全屏界面需要） |
| 睡眠待机优化 | 设置 → 电池 → 更多电池设置 | 若存在，把本应用排除 |

## 4. 上线前自测（每次改完都做一遍）

1. 主界面点「测试振动 8 秒」，此时**按音量减到底**——振动应当不受影响。
2. 手机调成静音 + 关闭「振动」总开关，再测一次，记录是否还能振（这是本方案最大的未知项）。
3. 点「立即测试全流程（5 秒后响）」，然后**立刻锁屏**，确认：
   - 屏幕自动亮起并显示输入界面
   - 输入错误不得放行，按返回键无效
   - 输入正确后振动停止，状态栏闹钟图标消失
4. 响铃中划掉通知 / 回桌面：振动应继续，界面 3 秒内重试弹出。
5. 重启手机：设置里的「下次闹钟」应自动重排。
6. 响铃中强行停止应用：这是无法防御的，记录现象即可。

## 5. 每晚例行

- 睡前看一眼主界面「下次」时间是否正确。
- 重要日子（考试/面试）**必须**同时设系统闹钟。
